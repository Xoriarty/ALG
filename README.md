# Отчет по лабораторной №1
## Вариант №9

### Часть 1. Алгоритмы поиска

Для реализации поиска элемента в массиве были использованы следующие методы:
- Линейный поиск
- Бинарный поиск
- Интерполяционный поиск

### Сравнительная таблица времени выполнения алгоритмов (Ticks)

| Размер массива | Линеный | Бинарный | Интерполяционный |
|----------------|---------|----------|------------------|
| 10 000         | 2357    | 1503     | 2057             |
| 150 000        | 4853    | 2018     | 2813             |
| 1 000 000      | 16433   | 2092     | 2819             |

P.S. При условии, что поиск модифицирован для нахождения **первого** вхождения элемента

### Сравнительная таблица сложности алгоритмов поиска

| Вид поиска       | Лучший случай      | Худший случай       | Средний случай      |
|------------------|--------------------|---------------------|---------------------|
| Линейный         | O(1)               | O(n)                | O(n)                |
| Бинарный         | O(1)               | O(log n)            | O(log n)            |
| Интерполяционный | O(1)               | O(log log n)        | O(n)                |

#### Вывод

**Бинарный поиск** показывает отличные результаты времени выполнения при различных размерах массива
**Интерполяционный поиск** также показывает отличные результаты
**Линеный поиск** показывает наихудший результат, особенно при очень больших размерах массива
